# 待办（AiTodo）· 产品计划表

> 文档版本：v1.0 ｜ 更新日期：2026-09-17
> 产品定位：面向 macOS 的极简四象限（艾森豪威尔矩阵）待办应用——把一件事放进四个格子，立刻做、计划做、委托做、减少做。

## 一、目标与北极星

| 项 | 内容 |
| --- | --- |
| 目标用户 | 桌面办公、多线并行的个人贡献者 / 团队成员（macOS 13+） |
| 核心价值 | 3 秒内记录一件事；打开即见"现在该做什么" |
| 北极星指标 | 周活跃用户的人均任务完成率 ≥ 60% |
| 护栏指标 | 冷启动 < 1s；数据零丢失；无网络依赖 |

| 里程碑 | 周期 | 主题 | 主要交付物 | 验收标准 | 状态 |

## 四、风险与依赖

| 风险 / 依赖 | 影响 | 应对措施 |
| --- | --- | --- |
| 通知权限被拒（macOS 需用户手动允许） | M2 提醒功能不可用 | 首次设置提醒时引导授权；拒绝时保留界面内红色过期标识兜底 |
| 本机 CommandLineTools 损坏（SPM 清单 API 缺符号、模块定义重复） | 构建链路不可用 | 已绕开：项目零第三方依赖，用 `swiftc` 直接编译 + 自研打包脚本；官方工具链已可解压使用；建议择机重装 CLT |
| 单人开发带宽 | 里程碑延期 | 每里程碑预留 2 天 buffer；优先砍 P2 功能保 P0 |
| Mac App Store 沙盒限制 | v2.0 上架 | M3 起在沙盒开关下回归测试通知与 CloudKit |
